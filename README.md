# Для тебя

Открытка-сайт: три вопроса, после которых над заснеженными холмами встаёт солнце и появляется письмо. Сделан под телефон, работает и на компьютере. Сборки нет, это обычные статические файлы.

## Как поменять содержимое

- **Текст письма** находится в `index.html`, в блоке `<article class="letter">`. Каждый абзац — отдельный `<p>`. Разбивка на предложения для анимации и неразрывные пробелы после коротких слов расставляются сами, в тексте их писать не нужно.
- **Дата годовщины, стартовая дата барабанов, подсказки и реплики на «Нет»** задаются в начале `assets/app.js`, в константах `ANSWER`, `START` и `TEXT`.
- **Вопросы и подписи кнопок** написаны прямо в `index.html`.

После первого прохождения сайт запоминает это в браузере и при следующих открытиях сразу показывает письмо. Кнопка «Пройти заново» под письмом сбрасывает запоминание.

## Как посмотреть локально

```sh
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

## Публикация на GitHub Pages

1. Создать репозиторий и запушить в него содержимое папки.
2. В репозитории открыть Settings → Pages, в Source выбрать «Deploy from a branch», ветку `main`, папку `/ (root)`.
3. Через минуту-две сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.

Картинка для превью ссылки в мессенджерах указана в `index.html` (`og:image`) полным адресом. Если репозиторий называется иначе, чем в этом адресе, адрес нужно поправить.

На бесплатном тарифе GitHub Pages работает только из публичного репозитория, поэтому текст письма можно прочитать в самом репозитории. Поисковикам индексировать страницу запрещено (`noindex`).
